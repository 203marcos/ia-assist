## Objetivo
Atuar em um time que pensa grande, trabalha com atenção aos detalhes, parceria no dia a dia e responsabilidade compartilhada. Crescer significa compartilhar conhecimento, respeitar diferentes formas de pensar e construir relações de confiança enquanto entrega tecnologia de qualidade.

## Responsabilidades
- Interpretar e compreender requisitos do projeto
- Colaborar com partes interessadas para esclarecer especificações
- Criar designs técnicos sólidos, considerando escalabilidade e manutenibilidade
- Desenvolver e executar testes unitários para garantir robustez do código
- Trabalhar em conjunto com desenvolvedores, arquitetos e profissionais de QA
- Participar de reuniões de planejamento e revisões de código
- Atualizar e manter código conforme requisitos evoluem
- Criar documentação clara e abrangente de código, design e processos
- Facilitar compreensão do sistema para outros membros da equipe
- Manter-se atualizado com tendências tecnológicas relacionadas a Java
